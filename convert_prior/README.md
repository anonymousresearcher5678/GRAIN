# Prior conversion

`convert_prior.py` turns the long-format CSV produced by
`synthetic_generation/` into the files the training code reads:

- a dense float64 matrix of series values (`<name>.y.npy`)
- a small metadata file (`<name>.meta.npz`)

## Usage

Put the CSV generated by R (for example `m3_yearly_200.csv`) in this folder, or
pass its path with `--csv`:

```bash
python convert_prior.py --csv m3_yearly_200.csv --out prior/
```

Then move `prior/` into `train_and_inference/`.

| Flag | Default | Meaning |
| --- | --- | --- |
| `--csv` | `m3_yearly_200.csv` | Source CSV. |
| `--out` | `prior` | Output folder. |
| `--name` | `m3_yearly_200` | Base name of the output files. |
| `--anchor` | `keep` | `keep` uses the CSV's own month-day anchor, which `first_fraction` in `blgt_2.Rmd` sets (1 = Jan-1, 0 = Dec-31). `random` draws a different month and day for each series. |
| `--anchor-seed` | `0` | Random seed used with `--anchor random`. |
